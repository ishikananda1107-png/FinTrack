# 💰 FinTrack – Personal Finance Tracking and Analysis System

FinTrack is a Python-based personal finance management application designed to help users track income, manage expenses and analyze their spending patterns.

## Features
- User Registration and Login
- Monthly Income Management
- Expense Tracking
- Machine Learning-Based Expense Categorization
- Expense History and Management
- Interactive Spending Analytics
- Category-wise Expense Visualization

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- Scikit-learn

## Machine Learning
Uses TF-IDF and LinearSVC for predicting expense categories based on expense descriptions.

## Installation

```bash
pip install streamlit pandas plotly scikit-learn
```

## Run the Application

```bash
streamlit run app.py
```
